# Traffic Analyser using YOLO and Machine Learning

## Overview

Traffic Analyser is an AI-powered smart traffic monitoring system developed using YOLO object detection and Machine Learning techniques. The project analyzes traffic videos in real time to detect vehicles, count traffic density, and identify helmet and non-helmet riders. It helps improve road safety and supports intelligent traffic management systems.

---

## Features

* Real-time vehicle detection and counting
* Helmet and non-helmet rider detection
* Traffic density analysis
* Multi-vehicle classification
* Video-based traffic monitoring
* History and analytics dashboard
* Fast and accurate detection using YOLO

## Modules

### Vehicle Counting

Detects and counts different types of vehicles from traffic video footage and displays live traffic statistics.

### Helmet Detection

Identifies whether bike riders are wearing helmets and highlights violations for safety monitoring.

### Analysis Dashboard

Displays traffic analysis results, statistics, and graphical insights for better monitoring.

### History Module

Stores previous traffic analysis records and allows users to review past data.

---

## How It Works

1. Input traffic video is provided to the system.
2. YOLO models process each frame of the video.
3. Vehicles and riders are detected in real time.
4. The system counts vehicles and checks helmet usage.
5. Results are displayed along with analysis data and stored in the database.
